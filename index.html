X Office 隐私政策

适用于 X Office · 文档阅读浏览器扩展。

更新日期：2026-09-22

X Office 只在 https://x.com/* 运行，将当前页面已加载的内容转换为办公文档外观。

扩展没有服务器、遥测或广告，不将你的账号、时间线或阅读清单发送给开发者。

扩展不读取 Cookie、密码或令牌，使用你在 X 页面上已有的登录会话。

文件名、显示偏好、工作占位文档和阅读清单保存在当前浏览器的扩展本机存储中，不使用云同步。清单最多保存 300 条摘录（含原文链接和图片 URL）。

扩展会在本机处理帖子正文、作者显示名与用户名、帖子链接、图片地址和点赞显示状态。为恢复阅读位置，当前标签页内存还会暂存最多 8 个 X 页面路径及阅读位置；这些信息不发送给开发者，也不使用 Chrome 浏览历史 API 读取其他网站的历史记录。

同一标签页的工作文档开关、待切换来源保存在 x.com 的 sessionStorage 中；页面阅读快照只在内容脚本内存中保存。

翻译由浏览器内置 Translator API 在本机执行，不将帖子正文发送至第三方翻译服务。首次使用时浏览器可能向其语言包服务器下载模型。译文与识别语言仅缓存在当前标签页内存中，刷新或关闭页面后清除，不写入阅读清单或云端。

X 原页面继续联网。展开图片时浏览器会向 pbs.twimg.com 请求媒体；点击外部链接会访问对应网站。扩展不会隐藏网络访问记录、浏览历史或地址栏。

你可以逐条移除阅读清单；卸载扩展会移除浏览器管理的扩展本机存储。关闭标签页会清除该标签页的临时状态。

开发验收使用的独立 Chromium 资料不属于扩展发布包；用户自行登录，资料保存在本机测试浏览器配置文件中。

扩展只申请 storage 权限，站点匹配范围仅为 https://x.com/*。不申请所有网站、Cookie、下载或浏览历史权限。

用途与数据使用承诺

页面内容仅用于文档式阅读、用户主动保存的本机阅读清单及本地翻译。扩展不出售用户数据，不将数据用于广告、画像、信用评估或借贷，不向开发者传输这些内容。我们不使用超出此单一用途的数据。

联系与变更

如对隐私有疑问，可通过扩展 Chrome 应用商店页面公开的开发者联系方式联系发布者。说明变更会更新本页日期。

X Office 是独立的第三方阅读扩展，与 X、Microsoft 或 Google 无隶属或背书关系。
